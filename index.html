Репозиторий

Исходники, инструменты воспроизведения, отчёт Редколлегии, журнал редакций, README на двух языках
  • Первая альфа вышла 8 октября 2026 года, через пять лет и пять месяцев после пятой версии.
  • Порог браузеров: Chrome и Edge 130, Firefox 132, Safari 18; ниже него нет ни полифилов, ни префиксов.
  • Почти каждая переменная Sass стала переменной CSS: оформление меняется в браузере без пересборки.
  • Шестнадцать оттенков в oklch, тринадцать ступеней каждого считает браузер функцией color-mix().
  • Диалог и ящик — на нативном <dialog>, аккордеон — на <details name>, карусель — на scroll-snap.
  • Сжатый CSS потяжелел с 226 до 372 килобайт, сборка JavaScript — с 78 до 214: цена универсальности.
