# Журнал редакций · Changelog

## 1.0.6 — 2026-10-17
- Страница скриншотов на узких экранах: сетка снимков больше не требует колонки шире 340 пикселей, и на телефоне шириной 320 пикселей подписи не выходят за край.

## 1.0.5 — 2026-10-11
- Из репозитория убрана папка `redkollegiya/` с отчётом вычитки и скрипт `tools/lang/apply.py`; ссылки на них сняты из README, llms.txt и титульной.

## 1.0.4 — 2026-10-11
- Терминология выровнена по принятому в русскоязычном сообществе словоупотреблению: Drawer и Offcanvas пишутся латиницей (вместо «ящик»), индикатор прогресса (вместо «полоса хода»), контрольные точки (вместо «точки перелома»), плавающие метки, OTP-поле, индикатор надёжности пароля, Nav overflow, заполнитель-скелет, свайп, адаптивный.
- Из доклада убраны служебные упоминания о процессе подготовки.
- В докладе снимок телефона (28-m-menu-drawer) получил класс для телефона, высокий снимок (19-glavnaya-cq-uzkaya) — оформление высокого снимка; снимки демо-сайта пересняты с новыми подписями.

## 1.0.3 — 2026-10-09
- Превью снимков переведены из JPEG в WebP: конвейер webmarka.kz конвертирует JPEG в WebP и переписывает ссылки только в обработанных файлах, из-за чего доклад на основной копии остался без картинок. Снимок 21-m-glavnaya ужат до предела WebP (16 383 px). Ссылки на оригиналы PNG — абсолютные, на GitHub Pages, где лежат файлы.

## 1.0.2 — 2026-10-09
- Основная копия исследования — https://webmarka.kz/research/bootstrap-6/; канонические адреса доклада, демо-сайта, страницы скриншотов и титульной переведены на webmarka.kz, GitHub Pages объявлен зеркалом; ссылки на доклад о Joomla 6 ведут на его основную копию webmarka.kz/research/joomla-6-newsroom/.

## 1.0.1 — 2026-10-09
- Демо-сайт назван прямо — «демо-сайт Bootstrap 6» — вместо вымышленного имени; переименование проведено по сайту, докладу, странице скриншотов, README, llms.txt; все 43 снимка сняты заново.

## 1.0 — 2026-10-09
- Первая редакция исследования: доклад (15 глав, 5 интерактивных графиков, 4 схемы, 58 источников, реестры Р и М, глоссарий из 18 терминов), демо-сайт Bootstrap 6 на версии 6.0.0-alpha.1 (7 страниц), «Сайт в скриншотах» (43 экрана, Chromium 153 через Playwright).
- Найдены и описаны расхождения в самой альфе: относительный цветовой синтаксис в токенах теней при политике браузеров, где он выше порога (Р-02); AGENTS.md против кода по версии Astro и числу слоёв (Р-01, Р-03); ошибка о втором экземпляре у комбобокса (М-01).
